# Origin / RAW / VIEW / Blind 验收标准

2026-10-31 用户批准。四组用于当前科研流程验收；原 P–A–B 的记录、失败和费用继续保留。首项使用 NbTiZrMoV 基准拉伸，后续研究采用相同分组原则。

## 四组的职责

| 组别 | 输入 | 执行方式 | 结果来源 |
|---|---|---|---|
| Origin，O，原文结果 | 论文图、表及其工况 | 提取原始数值；图中读数保存坐标标定和读数误差 | 作者已发表结果 |
| RAW，R，作者原样运行 | 完整作者代码、配套文件及论文条件 | Agent 负责准备环境、原样执行、查询和取回输出；不调用应用的科研规划、脚本改写和自动修正功能 | 作者原始工作流的实际输出 |
| VIEW，V，有参考的应用流程 | 作者论文、源码及配套资源 | Agent 通过 MCP 自行组织、编写或调整科研流程，完成执行、监视、分析和交接 | 有作者材料辅助的应用产物 |
| Blind，B，独立应用流程 | 独立参考 Agent 提取的自然语言需求、允许的同一势函数 | 执行 Agent 从新会话进入，通过 MCP 完成需求问答、建模、脚本、执行、分析与交接 | 独立用户流程的实际产物 |

RAW 的运行入口可以适配路径、队列和已验证引擎；记录原文件摘要及启动差异。科学脚本、采样和物理条件的更改保留为新尝试，不混入原样运行。论文条件与代码不一致时同时登记两种事实。

VIEW 可以学习作者代码，逐行转写仍属于 VIEW。保留原代码与生成版本、差异、模型设置、提示词及工具记录。

Blind 的执行端不接收论文全文、标题或链接、作者模拟与分析代码、Origin/RAW/VIEW 结果、旧 B 解法和评分反馈。参考 Agent 单独阅读论文，产出自然语言需求和私有来源表；只将需求传给执行端。提示词含研究目标、条件和成果要求，不含答案、命令序列或作者具体实现。未明确的科学选择通过问答和 Agent 方案处理。

同一势函数按许可、完整文件和元素映射提供，附必要的通用调用说明。默认由 Blind 自行生成结构；额外共享的结构数据须明确登记。势函数目录不夹带作者输入、专用分析或结果。通用官方文档、工具说明和独立于本案例的经验可用。

## 执行边界与计数

1. 参考端、VIEW 和 Blind 使用独立任务身份；Blind 的会话、文件、MCP 记录、资源及记忆访问范围共同受限。网络检索不能取回本案例论文、源码和答案。
2. 派发前实测允许文件可读、禁止文件不可读，检查资源检索、记忆、日志和错误消息不泄露参考答案。新目录和提示词约定本身不作为隔离证据。
3. 所有物理求值仍走已记账 HPC。RAW 仅使用执行和记账基础设施，不因此获得科研规划或修正辅助。
4. 本次新增 Blind 已获用户开展授权；先完成允许输入和隔离核验。正式 B 保留至多两次提交，检查、诊断、已有结果分析分别计数；不重建任务清零。
5. 同一比较记录模型与版本、引擎、核心数、内存、全部调用与失败、排队和运行时间、人工介入及费用。复用历史 RAW 时保留其历史环境与执行者，单独列出差异。
6. 调度结束、输出有效、科学检查和用户交付分别记录。每组保留未完成的需求，不用其他组数据补作本组成果。

## 同一张图的交付要求

最终提供一张包含四组的对比图，主面板为同一工况的应力–应变曲线，附强度和模量比较。组名固定为 Origin、RAW、VIEW、Blind，颜色、单位和图例一致。

- Origin 曲线只用原文数据或有来源的数字化点；保留图号、标定位置、像素坐标、缺失区间和读数误差。表格标量单独标识，不能由峰值和模量拼造整条曲线。
- 同时保留各组原始采样。比较前核对工程/真实应变、应力正负号、动能项、参考/当前体积和平均窗口；不能只因单位相同就视为同一物理量。
- 对本次数据，优先比较可对应的 10 ps 分块平均，VIEW 的 1 ps 分块在时间对应核对后合并。保留原始曲线，不能以峰值平移或按答案缩放改善吻合。
- 模量主窗口沿用 0–0.05，0–0.06 作为敏感性结果。Origin 保留原文给出的数值与其方法信息。不同初态和采样引入的差异单独解释。
- 附 CSV、绘图脚本和来源清单。每列追到组别、任务、输入版本、输出文件和分析方法；B 结束前，对比结果保留在参考端。
- 四组全部到齐后导出最终 PNG 与矢量文件。缺失组在进度记录中明确列出，完成状态由真实数据决定。

## 阶段完成条件

四组身份和输入边界可核对；O/R 复用依据完整；V/B 各自完成应用流程和成果检查；四组同图可打开、数据可追溯；失败、人工介入与成本完整。结果差异给出测量与解释，不预设必须与作者重合。
