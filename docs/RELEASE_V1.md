# Auto-LAMMPS MCP v1.0

2026年10月30日 · 发布标签 `v1.0` · Python 包 `1.0.0` · 数据库版本 2

在 Codex 或官方 DeepSeek Harness 中描述研究需求，由 Agent 编写原生科研脚本，软件保存项目、执行计算、监视进展并交接成果。

## 本版交付

- MCP 与命令行连接同一持久服务，保存需求、规则、操作、文件版本和费用。
- 复用已有势函数、项目与运行环境，提供版本化 LAMMPS 官方命令说明和已知错误检查。
- 本地记忆检索过去的方法、失败与成果；成套资源保留来源、元素映射及适用条件。
- 分级验证关联实际检查回执，按组件复用有效证据，条件变化只补相关检查。
- 批次保存独立样本、种子与验证来源，支持进度汇总、暂停恢复及跨对话接续。
- 原生分析支持失败恢复、方法修订、曲线与轨迹对应、成果版本和完整研究包。
- 固定安装提示词、版本安装器、平台连接、skill、用户指南与开发交付手册随版本发布。

## 安装和更新

从 README 复制原固定安装提示词。Agent 使用同一标签的安装器、wheel、校验摘要和指南。发布附件 `release.json` 保存源码提交、包版本与文件摘要；`SHA256SUMS` 用于核对下载文件。

macOS 提供托管安装与桌面后台。Linux 源码和隔离安装通过自动检查，服务管理需自行配置。Windows 原生安装继续开发。前台使用 Codex 或官方 DSH，计算使用已配置的 Slurm。

更新前保存现有数据库与项目备份，保留旧安装回执。数据库版本 2 的恢复流程见《后台与恢复》。运行中的研究继续使用其固定环境，完成后再安排升级。
